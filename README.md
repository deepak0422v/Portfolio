## 🚀 Getting Started

### Prerequisites

- Node.js `>=22.12.0`
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/deepak0422v/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

### Build for Production

```bash
npm run build
```

## 📦 Deployment

This portfolio is deployed on **Cloudflare Pages** with SSR via Nitro.

Every push to `main` triggers an automatic redeployment.

```bash
# Manual build + deploy (handled automatically by Cloudflare)
npm run build
```
